Data Science Methodology

1. Exploratory Data Analysis (EDA)

Analyzed data structure, checked for missing values, and visualized feature correlations to understand initial patterns.

2. Data Cleaning

Removed outliers from Fare_amount and Trip_distance using the IQR method to improve model stability.

3. Feature Engineering

Transformed categorical features like rate_code into numerical data using one-hot encoding so the model can read them.

4. Data Transformation

Corrected data skewness in key features using a Yeo-Johnson power transformation to create a "bell curve."

5. Scaling

Standardized all numerical features to a common scale, preventing any single feature from unfairly dominating the model.

6. Model Training

Trained multiple models, including Random Forest and Gradient Boosting, on the processed data to find the best predictor.

7. Evaluation & Serialization

Assessed models using R² on unseen test data and saved the best performers (.pkl) for deployment in an app.
