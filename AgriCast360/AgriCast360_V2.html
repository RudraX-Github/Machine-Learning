Core Prediction Engines

AgriCast360 V2 introduces dual prediction pipelines, combining historical market data with complex environmental variables.

💰

Crop Price Prediction

Predicts market prices at the Mandi-level. Integrates temporal features with environmental data to generate highly accurate price bands.

🌾

Yield & Supply Estimation

Estimates tons/hectare production capacity. Accounts for seasonal factors (Kharif/Rabi), area cultivated, historical yield baselines, and extreme climate risks.

🧠

Intelligent Model Routing

The system automatically selects the best-performing models based on the commodity's price range. Low-priced crops route to Linear/RF models, while high-value commodities route to Stacking/XGBoost.

⚡

Batch Processing Engine

Upload CSV files containing bulk feature data to process hundreds of predictions simultaneously across the ensemble network. Results are synthesized into downloadable reports.

The Model Zoo

Version 2 utilizes an ensemble of 9 specialized Machine Learning models trained on the 85 preprocessed features. Instead of relying on a single algorithm, the platform intelligently aggregates predictions to minimize error.

Model Architecture Type / Complexity Best Used For Inference Speed
Linear Regression (Base & Tuned) Baseline / Low Stable, linear relationships and low-price range commodities (< ₹5,000). Very Fast
Random Forest (Base & Tuned) Bagging Ensemble / Med Capturing non-linear weather relationships and extracting feature importance. Fast
XGBoost (Base & Tuned) Boosting Ensemble / High Complex pattern recognition; optimal for medium/high price bands. Medium
Voting Ensemble Simple Ensemble / High Robust consensus building across mid-range commodities (₹5k - ₹15k). Slow
Stacking Ensemble Meta-Ensemble / Very High Maximum accuracy for high-value premium commodities (> ₹15,000). Slow

System Architecture (V2)

The predictive pipeline is built entirely in Python using a serverless-friendly architecture, progressing from raw EDA to artifact inference via Streamlit.

1

Data Ingestion & EDA

Raw files from 3 markets containing 94 commodities are parsed. Extensive Exploratory Data Analysis generates insights into 7-30 day weather lags and high price volatility.

2

Feature Engineering & Preprocessing

Generation of critical interaction terms (e.g., Heat_Index_Proxy). The resulting 85 usable features undergo Strict Robust/Standard Scaling to normalize 14,000+ data samples against outliers.

3

Model Training & Artifact Storage

The 9 ensemble models are trained on the preprocessed feature matrix. Trained objects (`.pkl` files) and Scaler instances are uploaded to a centralized GitHub repository.

4

Dynamic Streamlit Inference

The UI dynamically pulls artifacts from GitHub, sanitizes real-time user input through the loaded `RobustScaler`, and executes the Parallel Inference Engine for rapid price/yield generation.
