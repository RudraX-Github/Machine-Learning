🎯 Objective

This preprocessing pipeline transforms raw engineered features into a normalized, properly scaled dataset optimized for machine learning models. The process reduces statistical irregularities (skewness and kurtosis) that can harm model performance, ensuring better convergence and more reliable predictions.

Feature Reduction Overview

Why 14 Features Were Removed?

During the preprocessing pipeline, certain features were excluded based on the following criteria:

  • Redundancy: Features with extremely high correlation (>0.99) or perfect linear relationships
  • Missing Data: Features with >50% missing values that couldn't be reliably imputed
  • Non-Numeric Types: Categorical features used for grouping (kept for reference, not modeling)
  • Identifier Columns: Original index/ID columns not needed for modeling
  • Target Variable: Modal_Price excluded from features (used as target)

Transformation Methods Applied

Transformation Type When Used Best For Advantages
Log Transform Positive right-skewed data with |skew| > 1 Price-related features Simple, interpretable, handles multiplicative relationships
Square Root Mild right-skew (0.5 < skew < 1) Moderate skewness Less aggressive than log, preserves more variance
Box-Cox Strictly positive features Optimized power transformation Finds optimal lambda parameter automatically
Yeo-Johnson Any distribution (handles negatives) Features with any range Most flexible, works with zero and negative values

Model-Specific Recommendations

🌲 Tree-Based Models (Random Forest, XGBoost, LightGBM)

Use: features_transformed.csv

  • Tree models are naturally resistant to non-normal distributions
  • Transformations help but scaling not critical
  • Handles outliers well without preprocessing
  • Best interpretability with transformed features

📈 Linear Models (Linear Regression, Ridge, Lasso)

Use: features_scaled_standard.csv

  • Assume normally distributed features
  • Require standardized scale for fair coefficient weighting
  • Transformations + scaling ensure model validity
  • Improved statistical inference and p-values

🧠 Neural Networks (Deep Learning, LSTM, CNN)

Use: features_scaled_standard.csv or features_scaled_robust.csv

  • Highly sensitive to feature scale and distribution
  • Normalized features dramatically improve convergence
  • Both scalers work well; choose based on data characteristics
  • Faster training with properly scaled inputs

🎯 Support Vector Machines (SVM)

Use: features_scaled_robust.csv

  • Distance-based algorithm, requires scaled features
  • RobustScaler better handles outliers than Standard
  • Transformations reduce decision boundary complexity
  • Critical for SVM performance

🔄 Ensemble Methods

Use: Mix of all files based on base learners

  • Use transformed for tree-based ensemble members
  • Use scaled for linear ensemble members
  • Diversity of preprocessing can improve ensemble performance
  • Stacking often benefits from normalized predictions
